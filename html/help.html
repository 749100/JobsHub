Profiles & Accounts

Where can I reset my password credentials?

Head to the main Login interface. Directly below the user access fields, you can select "Forgot Password" to route a secure reset token link directly to your registered inbound email account.

I am not receiving account verification tokens.

Cloud validation sequences drop tokens instantly. If missing, verify your local browser configuration isn't routing verification tokens to spam arrays, or wait 180 seconds before re-initializing the workflow.

Can I store multiple resume profiles?

Currently, your profile binds structural metrics to a single consolidated data node. To shift roles, update your central profile variables inside the My Profile workspace block.

Job Matching Pipelines

How do I verify if an application went through?

When you select "Apply Now", JOSHIPRO executes an active collection write to your cloud application cluster. If successful, the system records it inside your My Applications dashboard ledger.

How can I cancel or withdraw an application?

Submissions execute immutably into recruiter feed monitors. To declare a cancellation node, you will need to open a direct support ticket via our Contact Directory panel.

How are recruiter accounts authorized?

Corporate recruiter profiles require explicit administrative signing keys. If your institution needs deployment privileges, submit corporate validation files directly to the network team desk.

System Support

Components are frozen or text fails to change color.

This occurs if your system caches local asset frameworks. Hard-refresh your application viewport container by pressing Ctrl + F5 (or Cmd + Shift + R on macOS devices) to drop the expired layout assets.

Can I switch off the dark neon glass theme?

JOSHIPRO's dark glassmorphic neon layout engine is compiled directly into the root theme config variables to optimize user viewports. Standard light configurations are locked out by design.
